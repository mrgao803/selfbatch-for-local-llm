# 04 · 提示词规格（可执行）

> **本文件里的提示词逐字固定。** 除 `{{...}}` 替换位外，**一个字符都不能改**。
> 不得添加"请仔细思考""请分步骤"之类的指令。

---

## 一、全局参数

```
temperature = 0.7
top_p       = 0.9
seed        = 见下方规则
max_tokens  = 每题指定（见 §六）
system prompt = 不使用
```

**seed 规则**：

- 同一道题的三个条件（A0 / A1 / A2）用**同一组** seed，保证可比
- 每题独立跑 **3 个 seed**（如 101 / 202 / 303）
- 同一条件内重复运行时用同一 seed

---

## 二、请求类型清单

| 代号 | 用途 | 调用次数 |
|---|---|---|
| `R-OUT` | 生成大纲 | 每题 **1 次**，生成后固定，所有条件共用 |
| `R-A0` | 基线：一次写完 | 每题 × 每 seed × 1 次 |
| `R-A1` | 分段生成第 i 段 | 每题 × 每 seed × N 次（**并行**） |
| `R-A2-V1` | 融合修订（保守变体） | 每题 × 每 seed × 每轮 × N 次（**并行**） |
| `R-A2-V2` | 融合修订（中性变体） | 同上 |
| `R-A2-V3` | 融合修订（激进变体） | 同上 |

---

## 三、替换位定义

| 占位符 | 含义 |
|---|---|
| `{{材料全文}}` | 该题原始材料，逐字不变 |
| `{{N}}` | 该题段数（阿拉伯数字） |
| `{{大纲全文}}` | `R-OUT` 的输出，逐字不变，所有条件共用 |
| `{{i}}` | 当前段号（阿拉伯数字，从 1 开始） |
| `{{标题i}}` | 第 i 段的标题（从大纲中提取） |
| `{{全部段落全文}}` | 格式见 §四 |

### `{{全部段落全文}}` 的精确格式

**必须逐字按此格式拼接，段落按段号升序：**

```
【部分1：{{标题1}}】
{{部分1正文}}

【部分2：{{标题2}}】
{{部分2正文}}

【部分3：{{标题3}}】
{{部分3正文}}

...

【部分{{N}}：{{标题N}}】
{{部分N正文}}
```

- `部分` 与段号之间无空格
- 段号与标题之间是**中文全角冒号** `：`
- 段与段之间**空一行**
- 正文前后**不加任何额外说明**

**轮次规则**：

- **第 1 轮**：`{{部分i正文}}` = `R-A1` 的输出
- **第 r 轮（r ≥ 2）**：`{{部分i正文}}` = **同一变体**第 r−1 轮的输出

## 四、提示词全文

### `R-OUT` — 生成大纲

```
以下是原始材料：

{{材料全文}}

请为一份 {{N}} 个部分的文档列出大纲。每个部分一行，格式为「部分N：标题」。
只输出大纲，不要输出其他内容。
```

### `R-A0` — 基线，一次写完

```
以下是原始材料：

{{材料全文}}

请基于以上材料，写一份完整的文档，共 {{N}} 个部分：
{{大纲全文}}

要求：直接输出文档正文，不要输出其他内容。
```

### `R-A1` — 分段生成第 i 段

```
以下是原始材料：

{{材料全文}}

这是文档的大纲：
{{大纲全文}}

请只写其中的【部分{{i}}】，标题为「{{标题i}}」。
直接输出该部分正文，不要重复标题，不要写其他部分。
```

> **【硬性】本提示词里不得出现任何其他部分的正文内容。**
> 允许出现大纲（所有部分的标题），因为大纲是串行规划阶段的产物。
> **禁止出现任何其他部分的正文。**

### `R-A2-V1` — 融合修订（保守）

```
以下是一份文档的全部 {{N}} 个部分：

{{全部段落全文}}

请修订【部分{{i}}】，使其与其他部分在术语、事实、数字、时间线上保持一致。

规则：只做必要的修改。不需要改的地方保持原样。
只输出修订后的【部分{{i}}】正文，不要输出其他内容。
```

### `R-A2-V2` — 融合修订（中性）

与 V1 完全相同，**只把规则那一行换成**：

```
规则：检查是否存在不一致之处，并修正它们。
```

### `R-A2-V3` — 融合修订（激进）

与 V1 完全相同，**只把规则那一行换成**：

```
规则：仔细审查该部分与其余所有部分的衔接，全面改进一致性。
```

## 五、执行顺序（伪代码）

```
for task in tasks:
    outline = R-OUT(task)                    # 每题 1 次，之后固定不变

    for seed in [s1, s2, s3]:
        a0 = R-A0(task, outline, seed)       # 基线
        record(a0)

        base = parallel_for(i in 1..N):
                   R-A1(task, outline, i, seed)      # 一次并行，N 段
        record(base as round 0)

        for variant in [V1, V2, V3]:         # 三个变体各自独立跑
            cur = base                        # 都从同一份 A1 输出出发
            for k in 1..8:
                new = parallel_for(i in 1..N):
                          R-A2_<variant>(task, outline, cur, i)
                record(round=k, variant=variant, segments=new)
                cur = new                     # 替换，不累积到提示词里
```

**【硬性】三个变体是三条独立的链，互不影响。** 都从同一份 `base` 出发，各自跑满 8 轮。

**【硬性】每轮结束后用新段落替换旧段落**（不是把历史塞进提示词）。历史轨迹由执行方在文件系统里保留，不进提示词。

## 七、阶段一：batch 耗时测量的提示词

阶段一不需要任务材料，但需要**固定长度**的输入输出。

### 7.1 填充输入（约 2048 token）

任取一段中文文本（不要用任务材料），重复拼接直到 token 数为 **2048 ± 50**。
**所有 batch size 必须用完全相同的这段文本。**

### 7.2 生成提示词

```
请从 1 开始连续数数，每个数字单独一行，一直数下去，不要停止。
```

### 7.3 【硬性】生成控制

- 必须设置 **`ignore_eos = true`**（或等价的 `min_tokens = 256`）
- **强制生成满 256 个 token**，不允许提前停止
- 否则不同 batch 的输出长度不同，耗时不可比

### 7.4 测量流程（对 batch ∈ {1, 2, 4, 8, 16} 各做一遍）

1. **预热**：同 batch 跑 3 次，丢弃结果
2. **测量**：跑 5 次，记录：
   - `prefill_ms`：首 token 出现前的时间
   - `decode_ms`：首 token 到第 256 个 token 的时间
3. **取中位数**（不要用平均值）
4. 输出到 `results/phase1_batch_timing.json`（格式见 `03-executor-rules.md` §3.3）

### 7.5 必须单独算出的一个数

```
单步耗时比 = (batch=10 的 decode_ms ÷ 256) ÷ (batch=1 的 decode_ms ÷ 256)
         = batch=10 的 decode_ms ÷ batch=1 的 decode_ms
```

（若没测 batch=10，用 batch=8 或 16 的结果插值，并注明。）

**这个数先报告，等确认再进阶段二。**

## 八、每条请求都要记录的字段

```json
{
  "task_id": "P-B",
  "request_type": "R-A2-V1",
  "seed": 101,
  "round": 3,
  "segment": 2,
  "prefill_ms": 0,
  "decode_ms": 0,
  "output_tokens": 0,
  "wall_clock_ms": 0,
  "retry": false,
  "truncated": false,
  "prompt_hash": "<提示词的 sha256 前 8 位>",
  "timestamp": "ISO8601"
}
```

`prompt_hash` 用来事后核对提示词有没有被改过——**它是本实验的自证材料**。

## 九、最容易出错的三处

| # | 错误 | 后果 |
|---|---|---|
| 1 | 在 `R-A1` 里塞了其他段的**正文** | **实验作废**——你替它做了串行 |
| 2 | 融合轮次里把历史累积进提示词（而不是替换） | k 曲线失真 |
| 3 | 没设 `ignore_eos`，输出长度不一 | 耗时数据不可比 |

**这三条各违反一次，就要重跑。**
