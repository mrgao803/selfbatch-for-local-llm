## 自检记录

> 删掉第 2 部分，第 3 部分还能算对吗？
> **不能。** 第 3 级的折后价 P3 = P2 × d3、成本 C3 = C2 + (P2 − C2) × s3，两个输入 P2 与 C2 都是第 2 级算出来的结果；材料只给了第 2 级的折后系数与成本追加比例，并没有直接给出 P2、C2 的数值。而第 2 级的 P2、C2 又建立在第 1 级的 P1、C1 之上，所以第 2 部分被删后，第 3 部分的两个核心输入都无从取得，第 3 部分写不对。链是连续的。
> → 判定为信息串行，链长 = 3 ✓

（本小节不得出现任何由计算得出的具体数值。）

## 原始材料（逐字固定，998 个中文字符）

```
本题使用的商品代号为「云枢 P7」，销售渠道代号为「砺石」。该商品在渠道内参加一次三级递进促销，折扣与成本沿同一条链条逐级往下推：每一级的折后价在上一级折后价的基础上再打折，每一级的成本在上一级成本的基础上追加「紧邻上一级所算出的毛利」的一定比例。全部参数、公式与取整约定都写在本材料里，不需要任何外部资料或检索。

一、基准参数
挂牌价（第 0 级价格）P0 = 1280.00 元。
基础成本（第 0 级成本）C0 = 760.00 元。
促销从第 1 级开始，依次经过第 2 级、第 3 级。

二、逐级规则
折后价递推：P1 = P0 × d1，P2 = P1 × d2，P3 = P2 × d3。折后系数 d1 = 0.92、d2 = 0.88、d3 = 0.90，均为两位小数。

成本递推：C1 = C0 + (P0 − C0) × s1，C2 = C1 + (P1 − C1) × s2，C3 = C2 + (P2 − C2) × s3。成本追加比例 s1 = 0.20、s2 = 0.10、s3 = 0.08，均为两位小数。括号里的价差是紧邻上一级结束时算出的毛利，只能用它，不能改用更早一级的毛利。

毛利与让利额：M1 = P1 − C1，M2 = P2 − C2，M3 = P3 − C3；L1 = P0 − P1，L2 = P1 − P2，L3 = P2 − P3。
毛利率：g1 = M1 ÷ P1，g2 = M2 ÷ P2，g3 = M3 ÷ P3，均写成百分数形式。
累计让利额：T3 = L1 + L2 + L3，只在第 3 级结束后计算一次。

三、精度与单位约定
1. 折后价、成本、毛利、让利额一律以「元」为单位，每一步先四舍五入保留两位小数，取整后的值立刻作为下一级的输入；不得把未取整的中间值代入下一级。
2. 折后系数与成本追加比例由材料给定，保留两位小数，计算过程中不再取整。
3. 毛利率以「%」为单位，四舍五入保留两位小数；计算时使用该级已经取整的毛利与该级折后价，不要用未取整的数。
4. 累计让利额以「元」为单位，四舍五入保留两位小数，由三级已经取整的让利额相加得到。

四、待求
请按第 1、2、3 级的顺序，逐级写出该级的折后价、成本、毛利、让利额与毛利率，并在最后写出第 3 级结束后的累计让利额。每个结果都必须标明单位（元或 %）。
```
