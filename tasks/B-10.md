## 自检记录

## 原始材料（逐字固定，len() = 1205 个中文字符）

```
【结算批次代号：渡银 D-5】

本材料给出某跨境结算五步递推所需的全部参数与计算规则。五步依次衔接，每一步的输入是上一步算出的到账额。

一、计价与符号约定

1. 五步依次把上一步的到账额从一种货币折算为下一种货币，路径为：元 → 美元 → 欧元 → 英镑 → 港元 → 元。
2. 每一步的「汇率」指「1 单位目标货币折合多少单位源货币」。
3. 记 M(i) 为第 i 步的到账额，M(0) 为起始本金。
4. 每一步的「源货币」指本步折算前持有的货币，「目标货币」指折算后得到的货币。

二、初始条件

起始本金 M(0) = 600,000.00 元。

三、各步常数

以下四个常数在每一步分别为：基准汇率 H(i)、基准规模 B(i)、点调系数 s(i)、费率 f(i)。

第 1 步（元 → 美元）：H1 = 7.2400，B1 = 600,000.00 元，s1 = 0.1000，f1 = 0.0040
第 2 步（美元 → 欧元）：H2 = 1.0800，B2 = 85,000.00 美元，s2 = 0.1200，f2 = 0.0035
第 3 步（欧元 → 英镑）：H3 = 1.1700，B3 = 80,000.00 欧元，s3 = 0.0800，f3 = 0.0030
第 4 步（英镑 → 港元）：H4 = 9.9000，B4 = 65,000.00 英镑，s4 = 0.1500，f4 = 0.0025
第 5 步（港元 → 元）：H5 = 1.0870，B5 = 6,600.00 港元，s5 = 0.0600，f5 = 0.0020

四、计算规则（第 i 步，i = 1,2,3,4,5）

- 规模偏移量 D(i) = ( M(i−1) − B(i) ) ÷ B(i)
- 汇率 E(i) = H(i) × ( 1 + s(i) × D(i) )
- 手续费 F(i) = M(i−1) × f(i)
- 净额 N(i) = M(i−1) − F(i)
- 到账额 M(i) = N(i) ÷ E(i)

五、精度与取整顺序（必须严格遵守）

1. 先按上式算出 E(i)，四舍五入保留 4 位小数。
2. F(i) 与 N(i) 四舍五入保留 2 位小数。
3. 用取整后的 E(i) 与 N(i) 相除得到 M(i)，四舍五入保留 2 位小数。
4. D(i) 不单独取整，直接代入汇率公式。
5. 下一步一律使用上一步取整后的 M(i)，不得使用未取整的中间值。

六、输出要求与约束

1. 每一步写出 D(i)、E(i)、F(i)、N(i)、M(i)，并标注本步用到了前面哪一步的哪个结果。
2. 第 5 步的到账额即本批次的最终结算金额。
3. 每一步只能使用本材料给出的常数与上一步的到账额，不得跳跃引用。
4. 不得引入本材料未给出的任何参数。
```
