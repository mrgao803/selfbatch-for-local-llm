## 原始材料（逐字固定，1083 个中文字符）

```
供应链代号：青杧。该网络自上而下共设十一个节点，依次记为第 1 级至第 11 级，货物只能由上级流向下级，不能回流。

上游在第 1 级的初始到货量已给定：A1 = 3000.00 件。

每一级使用同一套递推规则，只是参数取值不同。设第 i 级的到货量为 Ai、本地消耗为 Ci，则该级期末库存为
Si = Ai − Ci。
若期末库存低于该级设定的目标库存 Ti，该级按缺口的一定比例紧急补货：当 Ti − Si > 0 时，Qi = αi × (Ti − Si)；当 Ti − Si ≤ 0 时，Qi = 0.00。其中 αi 为该级补货系数。
该级向下一级的转出量就是下一级的到货量：
A(i+1) = (Si + Qi) × (1 − pi)，
其中 pi 为该级转运损耗率。第 11 级为链末，不再向下转出。

各级参数取值如下（C、T 的单位均为件）：
第 1 级：C1 = 420.00，T1 = 1500.00，α1 = 0.60，p1 = 0.05；
第 2 级：C2 = 380.00，T2 = 1350.00，α2 = 0.50，p2 = 0.04；
```
