## 原始材料（逐字固定，1222 个中文字符）

```
本材料给出试验电芯「玄石 X5」在五段阶梯恒流放电中逐段推算所需的全部常数、公式、取整规则与流程，读者不需要任何外部资料，只需按顺序完成五段推算。文中代号与参数均为试验室内部编号，与任何市售产品无关。

一、固定常数
- 理想开路电压 OCV = 3.600 V，在五段放电全过程中保持不变
- 初始内阻 R0 = 0.0800 Ω，即第 1 段开始前的内阻
- 初始剩余电量 S0 = 12.000 Ah，即第 1 段开始前的剩余电量
- 第 1 段放电电流 I1 = 4.000 A，由试验台直接设定
- 电流衰减系数 a = 0.850（无量纲）
- 内阻增长系数 b = 1.100（无量纲）
- 内阻固定增量 c = 0.0040 Ω
- 时长基准系数 d = 0.600 h
- 基准电量 Sb = 12.000 Ah，仅用于把剩余电量折算成放电时长

二、通用规则
- 每段定义六个量：放电电流 I、内阻 R、放电时长 t、端电压 U、输出电量 Q、剩余电量 S，下标表示段号。
- 规则一（电流） I_k = I_{k-1} × a
- 规则二（内阻） R_k = R_{k-1} × b + c
- 规则三（时长） t_k = d × ( S_{k-1} ÷ Sb )
- 规则四（端电压） U_k = OCV − I_k × R_k
- 规则五（输出电量） Q_k = I_k × t_k
- 规则六（剩余电量） S_k = S_{k-1} − Q_k
- 第 1 段没有上一段：其内阻的上一段值取 R0，剩余电量的上一段值取 S0，电流直接取 I1。

三、取整与精度
- 所有乘除结果一律四舍五入，恰好为半值时向上进位，不采用奇偶舍入。
- I、t、Q、S 保留三位小数；R、U 保留四位小数。
- 每段算出的 I、R、t、S 必须先按上述精度取整，取整后的值才允许参与本段其余量的计算，也才允许代入下一段；U 与 Q 只在本段记录，不参与后续计算。

四、各段流程
- 第 1 段：电流取固定常数 I1，内阻的上一段值取 R0，剩余电量的上一段值取 S0，按规则一至规则六算出本段六个量。
- 第 2 段：以上一段即第 1 段算出的 I1、R1、S1 作为输入，按同一组规则算出本段六个量。
- 第 3 段：以上一段即第 2 段算出的 I2、R2、S2 作为输入，按同一组规则算出本段六个量。
- 第 4 段：以上一段即第 3 段算出的 I3、R3、S3 作为输入，按同一组规则算出本段六个量。
- 第 5 段：以上一段即第 4 段算出的 I4、R4、S4 作为输入，按同一组规则算出本段六个量。

五、输出要求
- 逐段写出第 1 段至第 5 段六个量并标明单位，代入的数值与计算结果都要写明。
- 最后单独给出第 5 段结束时的剩余电量。
- 五段按顺序计算，先算完前一段再算后一段，全部数值必须与取整规则一致。
```
