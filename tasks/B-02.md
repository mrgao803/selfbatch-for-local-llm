# B-02 · 露引 L7 植物基饮品三批次配方用量递推（3 步）

**类别**：B 信息串行·短链
**段数**：N = 3
**链长**：3
**预期 k**：2~5
**max_tokens（A0/A1）**：1500
**max_tokens（A2）**：600

## 自检记录

> 删掉第 2 部分（第 2 批的全部推算），第 3 部分还能算对吗？
> **不能。** 第 3 批的基粉投料量由递推式 M₃ = M₂ × [ 1 + (T − S₂) ÷ T ] 确定，其中 S₂ 是第 2 批成品的实测固形物含量，只能由第 2 批的投料量 M₂ 换算得到；而 M₂ 本身又是由第 1 批的 M₁ 与 S₁ 递推而来的。删掉第 2 部分后，第 3 部分既拿不到 M₂，也拿不到 S₂，材料里没有任何常数能替代这两个量，因此第 3 批的辅料用量、该批原料成本与三批累计总成本都算不出来。
> → 判定为信息串行 ✓

（本小节不得出现任何由计算得出的具体数值。）

## 原始材料（逐字固定，1009 个中文字符）

```
【产品代号：露引 L7】

本材料提供「露引 L7」植物基浓缩饮品三批次试制配方用量递推所需的全部参数、公式与规则，读者不需要任何外部资料，只需按顺序完成三批推算。三批依次记作第 1 批、第 2 批、第 3 批，每批成品目标灌装量相同，均为 Q = 500.0 L。原料共三种：基粉为主料，甜味剂与酸度调节剂为辅料。

一、第 1 批的投料起点
第 1 批基粉投料量 M₁ = 42.0 kg。
基粉在成品中的留存折算系数 η = 0.92；三批成品的实测固形物含量 S_i 均由该批基粉投料量换算得到，换算公式为（结果保留三位小数，单位为百分数）：
S_i = M_i × η ÷ Q × 100
其中 M_i 为该批基粉投料量（kg），Q 为成品灌装量（L）。
三批共用同一目标固形物含量 T = 4.800%。

二、第 2 批与第 3 批投料量的递推规则
自第 2 批起，每批基粉投料量按上一批成品的实测固形物含量与目标值的相对偏差调整，递推公式为（结果保留三位小数，单位 kg）：
M_i = M_{i-1} × [ 1 + (T − S_{i-1}) ÷ T ]
即上一批实测固形物含量低于目标值时本批加量，高于目标值时本批减量。第 2 批按第 1 批的 M₁ 与 S₁ 递推，第 3 批按第 2 批的 M₂ 与 S₂ 递推。

三、各批辅料用量
甜味剂用量 B_i = M_i × 0.035，结果保留三位小数（kg）。
酸度调节剂用量 A_i = M_i ÷ 220，结果保留三位小数（kg）。

四、各批原料成本
单价固定不变：基粉 26.40 元/kg，甜味剂 58.00 元/kg，酸度调节剂 12.50 元/kg。
第 i 批原料成本 C_i = M_i × 26.40 + B_i × 58.00 + A_i × 12.50，结果保留两位小数（元）。
三批累计原料总成本 C_总 = C₁ + C₂ + C₃，结果保留两位小数（元）。

五、精度与取值约定
（1）每批的 M、S、B、A 先按上式算出并保留到规定精度，再参与后续计算；
（2）后续步骤凡用到前面批次的量，一律取该批次已保留到规定精度的数值，不得使用未舍入的中间值；
（3）第 1 批只用材料给出的常数，第 2 批必须用第 1 批的结果，第 3 批必须用第 2 批的结果，不得跳批；
（4）本材料未给出的参数一律视为不参与计算。
```

## 分段方案

| 部分 | 内容 |
|---|---|
| 1 | 材料「一、第 1 批的投料起点」全节，加上「三、各批辅料用量」与「四、各批原料成本」中第 1 批（i = 1）的算式，以及「五、精度与取值约定」全部；产出 M₁、S₁、B₁、A₁、C₁ |
| 2 | 材料「二、第 2 批与第 3 批投料量的递推规则」中第 2 批（i = 2）的递推式，加上「三」「四」中第 2 批的算式；产出 M₂、S₂、B₂、A₂、C₂，其中 M₂ 依赖第 1 批的 M₁ 与 S₁ |
| 3 | 同一递推规则中第 3 批（i = 3）的递推式，加上「三」「四」中第 3 批的算式与「四」中三批累计总成本的算式；产出 M₃、S₃、B₃、A₃、C₃ 与 C_总，其中 M₃ 依赖第 2 批的 M₂ 与 S₂ |
